# «Прочее»: Spin и исправленный Bunny Hop

## Исправление Bunny Hop

Раньше переключатель включал прыжки без пробела, а ползунок менял JumpPower/JumpHeight. Это было усиление вертикального прыжка, а не разгон при банихопе. В этой версии поведение заменено.

- Включить «банихоп», затем **удерживать пробел и направление движения**.
- Без удержания пробела модуль не запрашивает прыжки и не добавляет ускорение.
- При приземлении и удержании пробела запрашивается обычный прыжок Humanoid.
- Ползунок **«сила разгона» — 0–50**, начальное значение **8**. Это прибавка к горизонтальной скорости в studs/с за один состоявшийся отрыв от земли, а не высота прыжка и не постоянное ускорение каждый кадр.
- Разгон направлен по Humanoid.MoveDirection. Без направления движения новый разгон не добавляется, но обычный прыжок при удержании пробела остаётся.
- **JumpPower, JumpHeight, UseJumpPower и WalkSpeed не изменяются.** При горизонтальном толчке сохраняется текущая вертикальная скорость, которую задаёт игра.
- За один полёт добавляется не больше одного толчка. Следующий возможен только после нового контакта с землёй. Повторное нажатие пробела в воздухе не даёт дополнительный толчок.
- При подтверждении отрыва требуются отсутствие поверхности под ногами, состояние Jumping/Freefall и положительная вертикальная скорость. Для рассинхронизации свойств на старте прыжка оставлено окно 0,25 с. Падение с уступа само по себе не разгоняет персонажа.
- Выбранный предел горизонтальной скорости — **120 studs/с**. Это настройка модуля, не измеренный лимит конкретной игры. Скорость выше этого значения, полученная другим способом, не урезается. Значение 0 на ползунке оставляет только повтор обычных прыжков при удержании пробела.
- Потеря фокуса окна, ввод в текстовое поле и свободная камера останавливают новые запросы прыжка и разгон. При выключении накопленная скорость не обнуляется — дальше её обрабатывает обычная физика игры.

## Spin

Spin вращает корневую часть вокруг вертикальной оси постоянно в одну сторону, без реверса. Скорость 30–1440°/с, по умолчанию 360°/с. AutoRotate временно отключается и возвращается при остановке.

Видимость Spin другим игрокам зависит от серверной репликации и владельца физики. Проверки со второго клиента не было, универсальная видимость не гарантируется.

## Установка

Для этого обновления заменить **`ShitaroHub/modules/misc.lua`** и **`ShitaroHub/modules/aim.lua`** на GitHub и заново выполнить прежнюю команду загрузки меню. `core/ui.lua` повторно менять не требуется: новый модуль уже включён в его список загрузки.

Если устанавливается полный архив, сохранить структуру:

```text
ShitaroHub/
├── core/ui.lua
└── modules/misc.lua
```

В полном архиве сохранены предыдущие улучшения аимбота и Spin. Модуль свободной камеры не менялся. Новых runtime-зависимостей нет. GitHub Raw может обновляться с задержкой.

Повторный запуск полного меню важен: он уничтожает предыдущий экземпляр и снимает старые изменения JumpPower/JumpHeight. Не запускать одновременно старый и новый модуль вручную.

## Жизненный цикл и ограничения

Обе функции изначально выключены. После респавна включённые настройки подхватывает новый Humanoid. Смерть, сидение, плавание, лазание, ragdoll, закреплённый корень и свободная камера приостанавливают функции. При закрытии меню физический обработчик отключается, прежний AutoRotate восстанавливается, если он всё ещё принадлежит модулю.

Горизонтальный разгон применяется к AssemblyLinearVelocity настоящего корня персонажа. Скрипт не отправляет выдуманные серверные команды и не обходит серверные ограничения. Сервер или игровой контроллер движения может сбрасывать скорость либо менять прыжок; работа в конкретном режиме требует проверки. Клиентский код не гарантирует сохранение буста на сервере.

## Проверки

Из корня проекта с CPython 3.9+ и системной библиотекой Lua 5.4:

```sh
python3 tools/check_misc.py
python3 tools/check_aim.py
```

При необходимости добавить `--lua-library /path/to/liblua-5.4.so`.

Тестируется настоящий modules/misc.lua с имитацией API. Основные проверки: отсутствие автопрыжков без пробела, горизонтальный импульс вместо увеличения высоты, сохранение Y-скорости, один толчок за полёт, разгон после следующего приземления, ограничение скорости, смена направления движения, отсутствие изменений свойств прыжка, фокус, текстовый ввод, свободная камера, респавн и закрытие. Прежние тесты Spin и аимбота также сохраняются.

Результаты: tests/misc_test_results.txt и tests/aim_test_results.txt. Это не запуск Roblox, Luau-компилятора, Xeno или серверной физики.

## Проверка в игре

1. Обновить файл и перезапустить меню целиком.
2. Включить банихоп и отпустить пробел: модуль не должен сам прыгать.
3. Удерживать W + пробел на ровной поверхности. При силе 8 повторные прыжки должны получать горизонтальную прибавку, без увеличения обычной высоты прыжка самим модулем.
4. Сравнить силу 0 и 20: при 0 остаются обычные прыжки с удержанием пробела, при 20 запрашивается больший горизонтальный толчок.
5. Отпустить пробел, проверить F-свободную камеру, респавн и закрытие меню. Если скорость немедленно сбрасывается, нужен лог фактической скорости в конкретном режиме — имитационные тесты этого не обнаруживают.

Откат: вернуть предыдущий modules/misc.lua и полностью перезапустить меню. Предыдущая версия снова будет использовать старое поведение изменения высоты.
