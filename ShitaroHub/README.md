# ShitaroHub

Меню + ESP + камера + аимбот для Roblox, разбитое на папки и файлы. Запуск одной строкой через инжектор.

## Структура

```
ShitaroHub/
├── loader.lua        точка входа: качает и запускает остальное
├── core/
│   ├── ui.lua        окно, вкладки, настройки, палитра, курсор, выход
│   ├── models.lua    помощник для 3D-моделей
│   └── viewmodel.lua поиск «вьюмодели» (руки и оружие от первого лица)
├── modules/
│   ├── esp.lua       ESP: box, line, name, distance, skeleton, health
│   ├── camera.lua    FOV, третье лицо, свободная камера
│   ├── aim.lua       аимбот и круг FOV
│   └── skins.lua     вкладка skins: смена модели игрока (карточка + сброс)
├── models/
│   ├── angel_v2.pack модель «Ангел» (меши + текстуры + превью одним файлом, 5,4 МБ)
│   ├── manifest.lua  список моделей для core/models.lua
│   └── README.md
└── tools/
    └── build_angel_pack.py  конвертер .glb в .pack (нужен только для пересборки)
```

## Запуск

Репозиторий: `laaloaoahfg-coder/ShitaroHub`, ветка `main`. Команда для инжектора:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/laaloaoahfg-coder/ShitaroHub/main/loader.lua"))()
```

Если репозиторий другой, поменяй `BASE_URL` в первых строках `loader.lua`.

## Загрузка на GitHub

Сохрани те же пути, что в структуре выше: `core/ui.lua`, `modules/esp.lua` и так далее. Через сайт: **Add file → Create new file**, в поле имени пиши путь с косой чертой (`core/ui.lua`), GitHub сам создаст папку. С компьютера можно перетащить папки целиком через **Upload files**.

## Локальный запуск (без интернета)

Положи папку в `workspace` инжектора под именем `ShitaroHub`:

```lua
getgenv().ShitaroConfig = { Mode = "local" }
loadstring(readfile("ShitaroHub/loader.lua"))()
```

## Вкладка skins

Открой вкладку **skins**: там карточка с аниме девушкой. Нажми на неё, и твой персонаж получит её модель. Кнопка **reset** возвращает обычный вид. Модель переживает респавн.

- Видно только тебе: это меняется на твоём клиенте, другие игроки видят обычного персонажа.
- При первом открытии вкладки файл `models/angel_v2.pack` скачивается один раз в папку `ShitaroHub/cache` инжектора и дальше берётся оттуда.
- Нужен инжектор с `writefile`, `readfile`, `isfile`, `makefolder` и `getcustomasset`. Если их нет, внизу карточки появится сообщение.
- Переключатель **flip faces** нужен, только если модель выглядит наизнанку (внутренности вместо поверхности). Включи его, и модель пересоберётся.
- Подходят R15 и R6. Размер модели подгоняется под рост твоего аватара.
- Скин прячет только само тело (части тела, аксессуары, лицо). Оружие, инструменты и любые модели, которые игра приваривает к руке, остаются видимыми и переносятся в ладонь модели.
- От первого лица руки вьюмодели (руки и оружие, которые игра рисует у камеры) заменяются руками модели: настоящие руки прячутся, оружие остаётся.
- Кнопка **copy diagnostics** копирует в буфер описание того, как устроена игра (что лежит под камерой, какие детали сварены с рукой). Если что-то выглядит не так, пришли этот текст.
- Если игра в новом раунде возвращает настоящую модель или заменяет части тела, скин сам прячет её обратно или пересобирается (проверка 4 раза в секунду).

Как это устроено: модель разрезана на 36 кусков по частям тела R15. Каждый кусок это `Part` с `SpecialMesh`, приваренный к своей части тела, поэтому он двигается вместе с анимациями. Из-за этого на сгибах (локти, колени) бывают небольшие щели.

## Камера

- **Третье лицо и свободная камера** прячут вьюмодель тремя способами: всё, что лежит под камерой; папки в Workspace с именами вроде `ViewModels` / `FirstPerson`; любая деталь рядом с камерой, которая «приклеена» к ней и двигается вместе с ней.
- **Свободная камера** только камера: персонаж стоит, убирается оружие (`Tool`), перехватываются вызовы игры с именами вроде `Shoot` / `Fire` / `Attack` и ответ «кнопка мыши нажата» (нужен `hookmetamethod`, без него этот шаг пропускается). Выключил камеру, и оружие возвращается в руки.

## Как это устроено

`loader.lua` скачивает `core/ui.lua` и запускает его. Ядро строит общий контекст и по очереди загружает `esp`, `camera`, `aim`. Если один модуль не скачался или упал, остальные работают, а причина пишется в консоль через `warn`.

`core/ui.lua` остался одним файлом (около 3 100 строк): его части связаны десятками общих переменных.
